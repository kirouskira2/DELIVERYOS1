# Framework de Auditoria V3.1

## 1. Qualidade de Código
- [ ] **Tipagem:** Zero `any`. Interfaces definidas para tudo.
- [ ] **Segurança:** RLS ativado em todas as tabelas? Inputs validados com Zod?
- [ ] **Performance:** Queries otimizadas? Uso correto de Server/Client Components?

## 2. Fidelidade Visual (MCPs)
- [ ] **Premium:** O código usa os componentes Tremor/Magic UI conforme especificado?
- [ ] **Fidelidade:** O resultado visual bate com o `prototype.html`?
