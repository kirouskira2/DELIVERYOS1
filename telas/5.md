# Implementação da Tela: Relatórios (Analytics)

## 1. Objetivo da Tela
Ofertat relatórios gerenciais consolidados do Delivery e Vendas B2B, permitindo filtrar grandes blocos de datas e fazer exportação dos resultados (PDF ou CSV).

## 2. Principais Funcionalidades / Botões
- Menu Dropdown: "Período (Ex: Últimos 30 dias, Este Ano)".
- Botão Secundário UI (Outline): **[Exportar Relatório]**. Ao clicar, utilize um package como `pdf` no Dart para gerar o documento dos dados plotados e acionar a caixa de download do browser/dispositivo com `url_launcher` ou o package adequado de salvamento de arquivos Web.
- Botão de **Atualizar Dados** (Busca limpa no Supabase).

## 3. UX de Análise Numérica e Listas Top 10
Crie seções abaixo dos gráficos focadas em ranqueamento:
- **Card: Pratos Mais Vendidos (Top Sellers):** Lista listando nome do prato e a quantidade de vezes pedida (via Left Join da tabela `pedido_itens` com `cardapio`).
- **Card: Melhores Clientes B2B:** Lista das empresas que dão maior LTV. Relacional entre `pedidos` e a chave estrangeira do `cliente`.

## 4. Gráfico Área de Desempenho Contínuo
Utilizando o `fl_chart` (LineChart mas preenchido como Área):
- Configure uma série (Area Series).
- Use `LinearGradient` sob a linha principal caindo até a base (translúcida).
- Eixo X contendo representações de semanas ou meses. Eixo Y para Volume financeiro.

## 5. Integração Backend Dart (Dica Sênior)
Nunca traga todos os pedidos do Banco para rodar as somas e o rankeamento no Cliente. Use Views (`CREATE VIEW...`) no PostgreSQL (Supabase) agrupando `pedido_itens` ou crie uma **Edge Function** no Supabase, para que o Flutter apenas faça o `GET /relatorio/top_sellers` já agregado. Isso torna a renderização ultra-rápida.
